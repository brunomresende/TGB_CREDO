# Dados

Os arquivos brutos e processados nao sao versionados.

- `raw/`: arquivos originais, sem alteracoes;
- `processed/`: um CSV por dataset, com a resposta na coluna `target`.

O benchmark completo espera `concrete.csv`, `airfoil.csv`, `winewhite.csv`,
`star.csv`, `winered.csv`, `cycle.csv`, `electric.csv`, `meps19.csv`,
`superconductivity.csv`, `homes.csv`, `protein.csv` e `WEC.csv`.

Downloads que exigem aceite de licenca ou procedimento manual nao sao feitos
automaticamente. O script nunca sobrescreve um arquivo bruto silenciosamente.
