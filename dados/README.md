# Dados

Os arquivos brutos e processados não são versionados.

- `brutos/`: arquivos originais, sem alterações;
- `processados/`: um CSV por conjunto, com a resposta na coluna `alvo`.

A comparação completa espera `concrete.csv`, `airfoil.csv`, `winewhite.csv`,
`star.csv`, `winered.csv`, `cycle.csv`, `electric.csv`, `meps19.csv`,
`superconductivity.csv`, `homes.csv`, `protein.csv` e `WEC.csv`.

Downloads que exigem aceite de licença ou procedimento manual não são feitos
automaticamente. O script nunca sobrescreve um arquivo bruto silenciosamente.
